# Lina Criativa | Mini Bíblias

Site estático pronto para upload manual no Git.

## Upload

Extraia o ZIP e envie o conteúdo para a raiz do repositório. index.html deve ficar na raiz, ao lado de styles.css, app.js, offer-config.js, vercel.json e assets/. Não envie somente o HTML e não renomeie os arquivos de assets.

Não é preciso instalar dependências nem executar build para esta página estática.
